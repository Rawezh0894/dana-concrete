# پوختەی پسووڵەکانی کۆنکرێت - Concrete Receipts Summary

## ناوەڕۆک (Contents)
ئەم سیستەمە پوختەی پسووڵەکانی کۆنکرێت دەکات و دەتوانرێت بە سایزی A4 چاپ بکرێت.

## تایبەتمەندییەکان (Features)

### 1. پوختەی گشتی (General Summary)
- کۆی گشتی پسووڵەکان
- کۆی گشتی بڕی مەتر سێجا
- کۆی کڕیاران
- بڕی تێکڕای مەتر سێجا

### 2. پوختەی کڕیاران (Customer Summary)
- ناوی کڕیار
- ژمارەی پسووڵەکان
- کۆی مەتر سێجا
- تێکڕای مەتر سێجا
- فۆرمۆلاکان

### 3. وردەکاری کڕیار (Customer Details)
- ژمارەی پسووڵە
- شوێن
- ناوی وەرگر
- بڕی مەتر سێجا
- فۆرمۆلا
- میکسەر و شۆفێری
- پەمپ و شۆفێری
- بەروار

### 4. فلتەرکردن (Filtering)
- فلتەرکردن بەپێی کڕیار
- فلتەرکردن بەپێی فۆرمۆلا
- فلتەرکردن بەپێی بەروار
- دوگمەی خێرای ئەمڕۆ/دوێنێ

### 5. چاپکردن (Printing)
- چاپکردن بە سایزی A4
- پوختەی گشتی
- پوختەی کڕیاران
- بەروار و کاتی چاپکردن

## بەکارهێنان (Usage)

### 1. دەست گەیشتن (Access)
لە پەیجی `concrete_receipts.php` دوگمەی "پوختەی پسووڵەکان" کلیک بکە.

### 2. فلتەرکردن (Filtering)
- کڕیار: هەڵبژاردنی کڕیاری دیاریکراو
- ڕێژە: هەڵبژاردنی فۆرمۆلای دیاریکراو
- بەروار: دیاریکردنی ماوەی بەروار
- دوگمەکانی خێرا: ئەمڕۆ، دوێنێ، ڕیفڕێش

### 3. بینینی وردەکاری (View Details)
کلیک لەسەر دوگمەی "وردەکاری" بۆ بینینی هەموو پسووڵەکانی کڕیارێک.

### 4. چاپکردن (Printing)
کلیک لەسەر دوگمەی "چاپکردن" بۆ چاپکردنی پوختە بە سایزی A4.
