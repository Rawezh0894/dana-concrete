# لۆجیکی باڵانسی کارمەند

## پێشەکی (Advance Payment)

پێشەکی بە شێوەیەکی تایبەت مامەڵەی لەگەڵ دەکرێت:

### لۆجیک
1. **یەکەم لە مووچە (payable_balance) دەکەم**: کاتێک کارمەند پێشەکی وەردەگرێت، یەکەم لە مووچەکەی دەکەم
2. **ئەگەر مووچە کەم بوو**: ئەو کات زیاد بە قەرزی کارمەند (receivable_balance)

### نموونە

#### حاڵەتی 1: پێشەکی لە مووچە دەکەم
```
مووچە: 600,000 د.ع
پێشەکی: 200,000 د.ع
→ باڵانس: 400,000 د.ع (600,000 - 200,000)
```

#### حاڵەتی 2: پێشەکی زیاتر لە مووچە
```
مووچە: 600,000 د.ع
پێشەکی: 200,000 د.ع → باڵانس: 400,000 د.ع
پێشەکی تر: 500,000 د.ع
→ باڵانس: 0 د.ع
→ قەرزی کارمەند: 100,000 د.ع (500,000 - 400,000)
```

#### حاڵەتی 3: چەند پێشەکی
```
مووچە: 600,000 د.ع
پێشەکی 1: 200,000 د.ع → باڵانس: 400,000 د.ع
پێشەکی 2: 150,000 د.ع → باڵانس: 250,000 د.ع
پێشەکی 3: 100,000 د.ع → باڵانس: 150,000 د.ع
```

## جۆرەکانی خەرجی

### 1. مووچە/بەخشیش/کاروانحیسابی
- **کار**: زیاد بە `payable_balance`
- **واتا**: کۆمپانیا قەرزی کارمەندە

### 2. پێشەکی
- **کار**: کەمکردنەوە لە `payable_balance`
- **واتا**: کارمەند پارەی لە مووچەکەی ڕادەکێشێت
- **ئەگەر مووچە کەم بوو**: زیاد بە `receivable_balance`

### 3. کەمکردنەوە/سزا
- **کار**: کەمکردنەوە لە `payable_balance`
- **واتا**: لە مووچە کەم دەکرێتەوە
- **ئەگەر مووچە کەم بوو**: زیاد بە `receivable_balance`

## باڵانسی خالص

```
باڵانسی خالص = payable_balance - receivable_balance
```

- **ئەگەر مثبت**: کۆمپانیا قەرزی کارمەندە
- **ئەگەر منفی**: کارمەند قەرزی کۆمپانیایە

## نموونەی تەواو

```
کارمەند: ئەحمەد
مووچە: 600,000 د.ع

1. مووچە 600,000 → payable_balance = 600,000
2. پێشەکی 200,000 → payable_balance = 400,000
3. بەخشیش 100,000 → payable_balance = 500,000
4. پێشەکی 300,000 → payable_balance = 200,000
5. کەمکردنەوە 50,000 → payable_balance = 150,000
6. پێشەکی 200,000 → payable_balance = 0, receivable_balance = 50,000

کۆتایی:
- payable_balance = 0
- receivable_balance = 50,000
- باڵانسی خالص = -50,000 (کارمەند قەرزی کۆمپانیایە)
```

## تێبینی گرنگ

1. **پێشەکی لە مووچە دەکەم**: پێشەکی یەکەم لە مووچە (payable_balance) دەکەم، نەک زیاد بە receivable_balance
2. **ترتیب گرنگە**: ترتیبی خەرجیەکان گرنگە بۆ هەژمارکردنی باڵانس
3. **Triggerەکان خۆکارن**: triggerەکان بە شێوەیەکی خۆکار باڵانسەکان ئاپدەیت دەکەن
