# ڕوونکردنەوەی هەژمارکردنی کارتەکانی باڵانس

## کارتەکان

لە پەیجی "بەڕێوەبردنی خەرجی کارمەند" دا سێ کارتی سەرەکی باڵانس هەیە:

1. **کۆی قەرزی کۆمپانیا** (`total_payable`)
2. **کۆی قەرزی کارمەند** (`total_receivable`)
3. **باڵانسی خالص** (`net_balance`)

---

## 1. کۆی قەرزی کۆمپانیا (Total Payable)

### مەبەست:
کۆی قەرزی کۆمپانیا بە هەموو کارمەندەکان (یان کارمەندی تایبەت ئەگەر فلتەر کرابێت).

### هەژمارکردن:
```sql
SELECT SUM(COALESCE(e.payable_balance, 0)) as total_payable
FROM employees e
WHERE e.id = ? -- ئەگەر فلتەر کرابێت
```

### چۆن `payable_balance` هەژمار دەکرێت؟

`payable_balance` لە `employees` تەیبڵەکەدا بە شێوەی خۆکار بە trigger-ەکان هەژمار دەکرێت:

#### زیادکردن بە `payable_balance`:
- **مووچە (salary)**: `payable_balance = payable_balance + amount`
- **بەخشیش (bonus)**: `payable_balance = payable_balance + amount`
- **کاروانحیسابی (overtime)**: `payable_balance = payable_balance + amount`

#### کەمکردنەوە لە `payable_balance`:
- **پێشەکی (advance)**: یەکەم لە `payable_balance` دەکەم
- **کەمکردنەوە (deduction)**: یەکەم لە `payable_balance` دەکەم
- **سزا (penalty)**: یەکەم لە `payable_balance` دەکەم

### نموونە:
```
کارمەند 1: payable_balance = 500,000
کارمەند 2: payable_balance = 300,000
کارمەند 3: payable_balance = 200,000

کۆی قەرزی کۆمپانیا = 500,000 + 300,000 + 200,000 = 1,000,000 دینار
```

---

## 2. کۆی قەرزی کارمەند (Total Receivable)

### مەبەست:
کۆی قەرزی هەموو کارمەندەکان بە کۆمپانیا (یان کارمەندی تایبەت ئەگەر فلتەر کرابێت).

### هەژمارکردن:
```sql
SELECT SUM(COALESCE(e.receivable_balance, 0)) as total_receivable
FROM employees e
WHERE e.id = ? -- ئەگەر فلتەر کرابێت
```

### چۆن `receivable_balance` هەژمار دەکرێت؟

`receivable_balance` لە `employees` تەیبڵەکەدا بە شێوەی خۆکار بە trigger-ەکان هەژمار دەکرێت:

#### زیادکردن بە `receivable_balance`:
کاتێک پێشەکی/کەمکردنەوە/سزا زیاتر لە `payable_balance` بێت:

```
IF payable_balance >= advance_amount THEN
    payable_balance = payable_balance - advance_amount
ELSE
    payable_balance = 0
    receivable_balance = receivable_balance + (advance_amount - payable_balance)
END IF
```

### نموونە:
```
کارمەند 1: receivable_balance = 100,000
کارمەند 2: receivable_balance = 50,000
کارمەند 3: receivable_balance = 0

کۆی قەرزی کارمەند = 100,000 + 50,000 + 0 = 150,000 دینار
```

---

## 3. باڵانسی خالص (Net Balance)

### مەبەست:
جیاوازی نێوان کۆی قەرزی کۆمپانیا و کۆی قەرزی کارمەند.

### هەژمارکردن:
```sql
net_balance = total_payable - total_receivable
```

### لۆجیک:
- **ئەگەر `net_balance > 0`**: کۆمپانیا قەرزی کارمەندەکانە (سەوز)
- **ئەگەر `net_balance < 0`**: کارمەندەکان قەرزی کۆمپانیان (سوور)
- **ئەگەر `net_balance = 0`**: باڵانس یەکسانە

### نموونە:
```
کۆی قەرزی کۆمپانیا = 1,000,000
کۆی قەرزی کارمەند = 150,000

باڵانسی خالص = 1,000,000 - 150,000 = 850,000 دینار
واتە: کۆمپانیا قەرزی کارمەندەکانە 850,000 دینار
```

---

## نموونەی تەواو

### دۆخی سەرەکی:
```
کارمەند 1:
  - مووچە: 600,000
  - پێشەکی: 250,000
  - payable_balance = 600,000 - 250,000 = 350,000
  - receivable_balance = 0

کارمەند 2:
  - مووچە: 500,000
  - پێشەکی: 600,000
  - payable_balance = 0 (لە 500,000 کەم بوو)
  - receivable_balance = 600,000 - 500,000 = 100,000

کارمەند 3:
  - مووچە: 400,000
  - پێشەکی: 0
  - payable_balance = 400,000
  - receivable_balance = 0
```

### کارتەکان:
```
کۆی قەرزی کۆمپانیا = 350,000 + 0 + 400,000 = 750,000
کۆی قەرزی کارمەند = 0 + 100,000 + 0 = 100,000
باڵانسی خالص = 750,000 - 100,000 = 650,000
```

---

## فلتەرکردن

### بە فلتەری کارمەند:
کاتێک کارمەندێک هەلبژێردرێت:
- تەنها باڵانسی ئەو کارمەندە پیشان دەدرێت
- نموونە: ئەگەر کارمەند 1 هەلبژێردرێت:
  - کۆی قەرزی کۆمپانیا = 350,000
  - کۆی قەرزی کارمەند = 0
  - باڵانسی خالص = 350,000

### بەبێ فلتەر:
- کۆی گشتی هەموو کارمەندەکان پیشان دەدرێت

---

## تێبینی گرنگ

1. **باڵانسەکان بە شێوەی خۆکار هەژمار دەکرێن**: کاتێک خەرجی زیاد/نوێ/سڕ دەکرێت، trigger-ەکان باڵانسەکان ئاپدەیت دەکەن.

2. **لۆجیکی پێشەکی**: پێشەکی یەکەم لە مووچە (payable_balance) دەکەم. ئەگەر مووچە کەم بوو، زیاد بە قەرزی کارمەند (receivable_balance) دەکرێت.

3. **باڵانسی ڕۆژانە**: کارتی تایبەتی "باڵانسی ڕۆژانە" بە شێوەی جیاواز هەژمار دەکات (مووچە بە شێوەی ڕۆژانە، پێشەکی بە تەواوی).

4. **کارتەکانی باڵانس**: لە `employees` تەیبڵەکەوە وەردەگرێت (کۆی گشتی).
