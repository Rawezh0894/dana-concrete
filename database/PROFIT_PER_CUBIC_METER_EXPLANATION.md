# ڕوونکردنەوەی هەژمارکردنی قازانجی خامی بۆ 1 م³ کۆنکرێت

## پێشەکی

ئەم سیستەمە قازانجی خامی بۆ هەر 1 م³ کۆنکرێت هەژمار دەکات بە شێوەیەکی خۆکار. ئەم کارتە لە پەیجی ڕاپۆرتدا دەبینیت و دەتوانیت کلیک لەسەر بکەیت بۆ بینینی وردەکاریەکان.

---

## هەژمارکردنەکان

### 1. تێچووی مەواد بۆ 1 م³

**چۆن هەژمار دەکرێت:**
- بە پێی فۆرمۆلەی کۆنکرێت (لە `concrete_formulas` تەیبڵ)
- نرخی مەواد لە `purchases` تەیبڵ (سەرەکی - بە پێی بەرواری فلتەر)
- یان لە `bins_silos` تەیبڵ (fallback - ئەگەر لە `purchases` نرخی بەردەست نەبوو)

**مەوادەکان:**
- لمی کەسارە (چاوی ١)
- لمی ڕەش (چاوی ٢)
- چەو (چاوی ٣ و ٤)
- چیمەنتۆ (سایلۆی ١: دەلتا + لاڤارج، سایلۆی ٢: ماس)
- دەرمان (زیادکراو)

**فۆرمۆلا:**
```
تێچووی مەواد بۆ 1 م³ = (کۆی تێچووی مەواد) ÷ (کۆی م³ فرۆشراو)
```

---

### 2. تێچووی کارمەند بۆ 1 م³

**چۆن هەژمار دەکرێت:**
- کۆی مووچەی کارمەندەکان لە `employee_expenses` تەیبڵ
- گۆڕینی بۆ دۆلار (مووچە بە دینارە)
- دابەشکردن بە کۆی م³ فرۆشراو

**فۆرمۆلا:**
```
تێچووی کارمەند بۆ 1 م³ = (کۆی مووچە بە دۆلار) ÷ (کۆی م³ فرۆشراو)
```

---

### 3. تێچووی سەیارەکان بۆ 1 م³

**چۆن هەژمار دەکرێت:**
- خەرجی سەیارەکان لە `other_expenses` تەیبڵ
- تەنها خەرجی سەیارەکان (کاتێک `car_id` نە NULL ە)
- گۆڕینی بۆ دۆلار
- دابەشکردن بە کۆی م³ فرۆشراو

**فۆرمۆلا:**
```
تێچووی سەیارەکان بۆ 1 م³ = (کۆی خەرجی سەیارەکان بە دۆلار) ÷ (کۆی م³ فرۆشراو)
```

---

### 4. تێچووی خەرجی ڕۆژانە بۆ 1 م³

**چۆن هەژمار دەکرێت:**
- خەرجی ڕۆژانە لە `other_expenses` تەیبڵ
- تەنها خەرجی تر، خواردنگە، و ئۆفیس
- گۆڕینی بۆ دۆلار
- دابەشکردن بە کۆی م³ فرۆشراو

**فۆرمۆلا:**
```
تێچووی خەرجی ڕۆژانە بۆ 1 م³ = (کۆی خەرجی ڕۆژانە بە دۆلار) ÷ (کۆی م³ فرۆشراو)
```

---

### 5. داهات بۆ 1 م³

**چۆن هەژمار دەکرێت:**
- کۆی داهات لە `sales` تەیبڵ
- بەکارهێنانی `price_per_unit * quantity` (بە دۆلار)
- یان `amount_paid_usd` یان `amount_paid_iq` (گۆڕدراو بۆ دۆلار)
- دابەشکردن بە کۆی م³ فرۆشراو

**فۆرمۆلا:**
```
داهات بۆ 1 م³ = (کۆی داهات بە دۆلار) ÷ (کۆی م³ فرۆشراو)
```

---

### 6. قازانجی خامی بۆ 1 م³

**چۆن هەژمار دەکرێت:**
```
قازانجی خامی = داهات - تێچوو

تێچوو = تێچووی مەواد + تێچووی کارمەند + تێچووی سەیارەکان + تێچووی خەرجی ڕۆژانە
```

**ڕێژەی قازانج (%):**
```
ڕێژەی قازانج = (قازانجی خامی ÷ داهات) × 100
```

---

## نموونە

### دۆخی سەرەکی:
```
کۆی م³ فرۆشراو: 100 م³

تێچووی مەواد: $2,500
تێچووی کارمەند: $500
تێچووی سەیارەکان: $300
تێچووی خەرجی ڕۆژانە: $200
کۆی تێچوو: $3,500

داهات: $4,500
```

### هەژمارکردن:
```
تێچووی مەواد بۆ 1 م³ = $2,500 ÷ 100 = $25.00
تێچووی کارمەند بۆ 1 م³ = $500 ÷ 100 = $5.00
تێچووی سەیارەکان بۆ 1 م³ = $300 ÷ 100 = $3.00
تێچووی خەرجی ڕۆژانە بۆ 1 م³ = $200 ÷ 100 = $2.00
کۆی تێچوو بۆ 1 م³ = $25 + $5 + $3 + $2 = $35.00

داهات بۆ 1 م³ = $4,500 ÷ 100 = $45.00

قازانجی خامی بۆ 1 م³ = $45.00 - $35.00 = $10.00
ڕێژەی قازانج = ($10.00 ÷ $45.00) × 100 = 22.22%
```

## تێبینی گرنگ

1. **فلتەرکردن**: هەژمارکردنەکان بە پێی فلتەری بەروار دەکرێن (ئەمڕۆ، ئەم هەفتە، ئەم مانگ، ئەم ساڵ، یان بەرواری تایبەت).

2. **نرخی مەواد**: یەکەم لە `purchases` تەیبڵ وەردەگرێت (بە پێی بەرواری فلتەر). ئەگەر بەردەست نەبوو، لە `bins_silos.average_price` وەک fallback وەردەگرێت.

3. **گۆڕینی دراو**: هەموو بڕەکان بە دۆلار هەژمار دەکرێن بۆ یەکسانکردن.

4. **کارتی قازانج**: لە پەیجی ڕاپۆرتدا کارتێک هەیە بە ناوی "قازانجی خامی بۆ 1 م³ کۆنکرێت". کلیک لەسەر بکە بۆ بینینی وردەکاریەکان.

5. **ڕوونکردنەوە**: کاتێک کلیک لەسەر کارتی قازانج دەکەیت، وردەکاریەکانی هەژمارکردنەکان پیشان دەدرێت.

3. کارتی "قازانجی خامی بۆ 1 م³ کۆنکرێت" ببینە
4. کلیک لەسەر کارتەکە بکە بۆ بینینی وردەکاریەکان
